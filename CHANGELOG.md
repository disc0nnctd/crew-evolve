# Changelog

## 0.2.0rc1

Release candidate preparation is in progress. This entry records the current
candidate contents without making a publication or production-readiness claim.

- Added source-scoped boolean, enum, and date conversions with tested preview,
  versioned reuse, bounded historical replay, rejection evidence, and rollback.
- Added bounded reviewed workflow matching, exact duty binding, and optional
  offline model candidates with inspectable evidence.
- Added revision-keyed engine snapshots and reusable indexes, with reference
  comparisons and tests for mutation and concurrent reads.
- Added consistent local workspace backup and restore into new destinations.
- Added a frozen synthetic adaptation evaluation, full-request load metrics,
  recorded demo, and [measured limitations](docs/BUILD_VERIFICATION.md).
- Added source and wheel packaging for the Python application.
- Copied web assets and example CSV files into built distributions.
- Added installed-resource lookup with checkout fallback for development.
- Added package smoke checks for wheel and source archive installs outside the
  checkout, including real browser correction and reuse flows.
- Added an optional `local` extra for Python 3.11 or later.
- Added release preparation guidance for installation, contribution,
  security, and third-party dependency review.

The repository remains private. License selection, publication, and final
release notes are pending owner review.
