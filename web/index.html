Scan assignments for every crew member. Sum each rolling window independently. Simple enough to check the optimized path against.

Find assignments by crew and position. Integrate duty-time events, then use binary searches to calculate rolling hours.

What the scores mean

Correctness score

Exact agreement with reference results. Every measured and held-out case must pass before selection.

Response time

Median and 95th-percentile latency include building indexes and generating the complete result. No cache hits.

Scale and memory

Compare latency growth to data growth, queries per second, and peak allocated memory. Measurements are local, not a service guarantee.

The optimization agent selects from reviewed algorithms. It does not run model-generated code. Repeated workspace queries also use a bounded cache invalidated whenever data or policy changes.
